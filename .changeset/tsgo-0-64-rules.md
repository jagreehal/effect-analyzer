The semantic diff and `review` report a step swapped for a different callee at the same position as `replaced`. `review` lists each replacement for a reviewer to confirm and grades the change moderate. `--diff` against a git ref or a GitHub PR reports a failed lookup as a `CliError` with the underlying message. Supports `@effect/tsgo` 0.64.1 and Effect 4.1.2.
